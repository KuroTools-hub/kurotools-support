# KuroTools Support Site

PDF.Flatten.Optimizerの公開サポートサイト、プライバシーポリシー、GitHub Issues用の不具合報告フォームです。アプリ本体のソースコードは含みません。

## 公開手順

1. GitHubでPublicリポジトリ `kurotools-support` を作成します。
2. このフォルダの**中身**をリポジトリ直下へアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/(root)` にして保存します。
6. 数分後、次のURLを確認します。

- サイト: `https://GITHUBユーザー名.github.io/kurotools-support/`
- サポート: `https://GITHUBユーザー名.github.io/kurotools-support/support/`
- プライバシー: `https://GITHUBユーザー名.github.io/kurotools-support/privacy/`

サポートページの「不具合を報告」ボタンは、GitHub Pagesのホスト名からユーザー名を自動判定します。ユーザー名をファイルへ書き込む作業は不要です。

## Microsoft Storeに登録するURL

- Support contact info: 上記のサポートURL
- Privacy policy URL: 上記のプライバシーURL

## 公開前の確認

- GitHubリポジトリでIssuesが有効になっていること
- プライバシーポリシーの日付とアプリの実際の動作が一致していること
- アプリ内の「バージョン情報」に同じURLを設定すること
- 問い合わせ投稿に機密PDFを添付しない注意書きが表示されること
