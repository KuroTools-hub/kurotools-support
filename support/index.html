不具合を報告 / Report an issue

最初に確認すること

  1. 元PDFが別のアプリで正常に開くか確認します。
  2. PDF.Flatten.Optimizerを最新版に更新します。
  3. 出力先に十分な空き容量と書き込み権限があるか確認します。
  4. 表示されたエラーメッセージを控えます。

よくある質問

元のPDFは変更されますか？

変更されません。結果は _flat、_opt_H、_compress_M、_raster_200dpi_C などの接尾辞を付けた別ファイルとして保存されます。

画像化するとファイルが大きくなることがありますか？

あります。元PDFが文字や単純なベクター中心の場合、ページ全体を画像にすることでサイズが増える場合があります。

変換が安全のため停止しました。

未対応のPDF構造を検出した可能性があります。別モードを使用するか、機密情報を除いたエラー内容を報告してください。

報告に含める情報

  • アプリのバージョン
  • Windowsのバージョン
  • 処理モードと設定
  • エラーメッセージ全文（機密部分は伏せる）
  • 同じ操作で再現するか

Before reporting a problem

Confirm that the source PDF opens normally, update the app, check available disk space, and keep the exact error message. Reports are public: never include confidential PDFs, personal information, customer data, or sensitive filenames.
